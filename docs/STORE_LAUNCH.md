# Store Launch (Phase 8)

Steps: test track → closed (50 friends) → open.

## Gates (all must pass)
- 50 test users
- Share works ≥ 60%
- Back in 7 days ≥ 30%
- Zero big bugs
- Crash-free > 99.5%

## Privacy (short)
- Photos stay on phone. We ask photo access only.
- Account only for sync. Delete wipes data.
- Posts are public. Chat stays in app. No phone shown.

## Data safety form answers
- Collects: photos picked by user, account name/email, app counts.
- Shares: nothing sold. Files go to WhatsApp only when user taps.
- Delete: in Settings → Delete account.
